# Credits

Third-party assets shipped with ShipNLearn. Every file below is **CC0 1.0**
(public domain dedication, https://creativecommons.org/publicdomain/zero/1.0/):
no attribution is required, we credit the authors because they deserve it.
Sound effects are synthesized in code (`src/lib/audio/sfx.ts`) and need no credit.

## Music

Files were normalized to about -14.5 LUFS (true peak <= -1 dBTP) and re-encoded
to 128 kbps MP3. Nothing else was changed; the loops are the authors' own
seamless loops.
